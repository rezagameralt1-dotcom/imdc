## اسکریپت اسموک اند-تو-اند (محصول/انبار/سفارش)

این اسکریپت برای تست سریع جریان کامل بازار طراحی شده است و بدون نیاز به وابستگی‌های اضافی (مثل jq) اجرا می‌شود.

### پیش‌نیازها
- سرویس API در حال اجرا (پیش‌فرض: `http://127.0.0.1:8000`)
- ایجاد کاربر و داشتن ایمیل/پسورد معتبر
- PHP و cURL روی سیستم در دسترس باشد

### متغیرهای محیطی
قبل از اجرا متغیرها را تنظیم کنید (نمونه):
```bash
export API_BASE="http://127.0.0.1:8000"
export EMAIL="user@example.com"
export PASSWORD="your-strong-password"
```

### اجرای اسکریپت
از ریشه پروژه (پوشه backend):
```bash
./scripts/smoke_e2e.sh
```

### کارهایی که اسکریپت انجام می‌دهد
1. ورود و دریافت توکن Sanctum
2. ساخت محصول با SKU یکتا و فعال‌سازی آن
3. افزایش موجودی (delta=+10)
4. ایجاد سفارش با تعداد 2
5. در صورت نیاز، رزرو موجودی برای سفارش
6. پرداخت سفارش
7. چاپ خلاصه نهایی شامل PRODUCT_ID، ORDER_ID، وضعیت سفارش و مقادیر موجودی

در صورت خالی بودن هر مقدار حیاتی (توکن، شناسه محصول یا سفارش) اسکریپت با خطا خاتمه می‌یابد.
